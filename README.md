# Open Retail India

Mobile-first Tamil + English retail billing and inventory starter.

## Version 1.3
- Sales returns increase stock
- Purchase returns reduce stock (cannot exceed available stock)
- Stock adjustments for damage, loss, count correction or found stock
- Customer and supplier outstanding summaries from manual ledger entries
- Daily activity report for sales, returns and purchases
- Existing billing, customer/supplier, purchase entry, themes and JSON backup retained

## Important limitations
This is a local browser prototype. Data stays in this browser's local storage. Returns are stock-operation records only; they do not automatically issue GST credit/debit notes, refund money, reverse invoice tax, or update party ledgers. The daily report is not a complete profit-and-loss statement and excludes COGS and operating expenses. No cloud sync, authentication or statutory accounting compliance is provided. Back up data regularly.

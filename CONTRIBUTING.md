# Contributing to Open Retail India

Thanks for considering a contribution!

1. Search existing Issues before opening a new one.
2. For bugs, include device, browser, steps to reproduce, expected result and actual result.
3. For feature requests, explain the real shop workflow the feature supports.
4. Keep changes small and focused.
5. Do not include real customer, bank, phone or business-private data in screenshots or test fixtures.
6. Test on a narrow mobile screen and check both Tamil and English labels.
7. Open a Pull Request with a clear summary and screenshots where useful.

All contributions are subject to the MIT License.
